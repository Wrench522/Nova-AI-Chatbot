# Submission checklist

- [ ] Add your own OpenAI API key in local `.env` or hosting environment variables.
- [ ] Run locally and test the chat.
- [ ] Customize the branding/content to make the work your own.
- [ ] Capture screenshots of homepage, conversation, history and mobile layout.
- [ ] Push source code to GitHub (never commit `.env`).
- [ ] Deploy to a Python host and configure environment variables.
- [ ] Add GitHub and live links to your internship submission.
